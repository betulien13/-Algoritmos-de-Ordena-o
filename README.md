
Atividades de Algoritmos e Programação

Repositório destinado à organização e disponibilização das atividades práticas desenvolvidas em aula e do Projeto 4 — Algoritmos de Ordenação.

 Objetivo

Reunir os exercícios e projetos desenvolvidos durante as aulas, permitindo acompanhar os conteúdos estudados e aplicar os conceitos de programação na resolução de problemas.

 Organização do Repositório

As atividades estão separadas em pastas, organizadas conforme os exercícios e conteúdos desenvolvidos em aula.

Cada pasta contém seus respectivos arquivos de código-fonte, facilitando a identificação, consulta e correção das atividades.

 Projeto 4 — Algoritmos de Ordenação

Projeto desenvolvido com o objetivo de aplicar e compreender diferentes métodos de ordenação de dados utilizando a linguagem C.

Conteúdos abordados

- Bubble Sort
- Selection Sort
- Organização e manipulação de vetores
- Estruturas de repetição
- Funções em C
- Comparação e troca de elementos

 Tecnologias utilizadas

- Linguagem C
- GDB Online
- GitHub

 Observações

- As atividades estão organizadas em pastas individuais.
- Os arquivos estão disponíveis para consulta e avaliação.
- O repositório reúne os exercícios realizados durante as aulas e o Projeto 4.
