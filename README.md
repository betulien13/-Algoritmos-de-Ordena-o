
Atividades de Algoritmos e Programação

Repositório destinado à organização e disponibilização das atividades práticas desenvolvidas em aula 

 Objetivo

Reunir os exercícios desenvolvidos durante as aulas, permitindo acompanhar os conteúdos estudados e aplicar os conceitos de programação na resolução de problemas.

 Organização do Repositório

As atividades estão separadas em pastas, organizadas conforme os exercícios e conteúdos desenvolvidos em aula.

Cada pasta contém seus respectivos arquivos de código-fonte, facilitando a identificação, consulta e correção das atividades.

 Tecnologias utilizadas

- Linguagem C
- GDB Online
- GitHub

 Observações

- As atividades estão organizadas em pastas individuais.
- Os arquivos estão disponíveis para consulta e avaliação.
- O repositório reúne os exercícios realizados durante as aulas
